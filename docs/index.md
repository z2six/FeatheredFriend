# FeatheredFriend Wiki

This wiki is built with **MkDocs + Material** and deployed to **GitHub Pages** via GitHub Actions.

!!! note
    This is just the scaffold. Add pages under `docs/` and link them in `mkdocs.yml`.

## Notes / Disclaimers (Admonitions)

!!! warning "Work in progress"
    Content here may change as the mod evolves.

## Collapsible Sections (Spoilers)

??? note "Click to reveal"
    You can use collapsible blocks for spoilers, long logs, etc.

## Images

Put images in `docs/assets/images/` and reference them like:

```md
![Example](assets/images/example.png)
```

## Audio

Put audio in `docs/assets/audio/` and embed it with HTML:

```html
<audio controls>
  <source src="assets/audio/example.ogg" type="audio/ogg">
</audio>
```
